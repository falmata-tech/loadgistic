# Ethiopia place catalog

`ethiopia-settlements.json` is a bounded OpenStreetMap-derived catalog used for
Loadgistic city, town, village, hamlet, and Addis Ababa locality search. It is
stored with the application so a database reset and a new environment receive
the same geographic baseline without calling a geocoder during user input.

Source: OpenStreetMap contributors, via the Overpass API. OpenStreetMap data is
available under the Open Data Commons Open Database License (ODbL).
