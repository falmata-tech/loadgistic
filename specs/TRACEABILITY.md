All features depend on `BASE-BE-001`; user-facing features depend on `BASE-FE-001`; runtime and release constraints derive from `BASE-DEP-001`.

Cross-feature authorization contracts are mapped in `docs/AUTHORIZATION_MATRIX.md` and verified by `tests/authorization.test.mjs`.

Playwright runs through `BrowserTestRuntime` on port `3100` with `data/test-e2e.db`; it never reuses the development server or `data/loadgistic.db`.

The local visual audit (`npm run test:ui-audit`) covers 208 logged-out and role-scoped screens at desktop and mobile sizes, including the producer homepage, Fleet Transporter dashboard, company Driver capacity Home, truck-specific fleet capacity controls, My Network states, searchable Boards, pooled-shipment detail, route evidence maps and comparison, Post Shipment, execution-only Tracking, verification workflows, member Support, SUPPORT queues/conversations, admin Support supervision, admin Operations and Rating Reviews, assigned-shipment controls, and secret-code customer tracking. Its report checks response status, horizontal overflow, touch target size, unlabeled controls, icon coverage, empty commands, and browser errors; screenshots and `report.json` are written to the ignored `artifacts/ui-audit/` directory. The July 2026 verification run captured all 208 screens with zero automated layout/accessibility flags and zero browser-flow errors.

The comprehensive dataset test validates all 34 application tables, more than 8,000 standard-profile rows, structured route coordinates, foreign keys, entity ownership, fleet assignments, generated authentication, mixed movement scopes, support queues, unique named network relationships, cross-member visibility, published-rating projection, and production denial. After `npm run db:stress`, `npm run test:ui-stress` captures 74 dense desktop/mobile screens across six personas, including Connected, Requests, Favorites, Partners and Direct visibility, second-page Board, Directory, and Operations results, mixed coverage comparison, and expired billing mode. It checks expected cohort content, status, browser errors, overflow, render time, DOM size, card density, and requested-page visibility. Its ignored evidence is written to `artifacts/stress-ui/`.
